## Quick reference (this lesson)

| Component | Purpose | Install |
|-----------|---------|---------|
| `transformers` | models + pipelines | `pip install transformers` |
| `torch` | default execution backend | `pip install torch` |
| `sentencepiece` | BPE/SentencePiece tokenizers (T5, Llama, …) | `pip install sentencepiece` |
| `accelerate` | multi-GPU / mixed-precision helpers | `pip install accelerate` |
